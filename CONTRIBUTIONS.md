# Contribution rules and record

Use your own GitHub account. Create issues for material tasks, branches for substantial changes and reviewed pull requests for core metrics, AI, verification and review controls. Commit progressively with clear descriptions. Link decisions and evidence to deliverables.

Teams replace this starter table with real evidence:
| Member / handle | Role | Issue | PR / commit | Artifact / result | Peer review |
|---|---|---|---|---|---|

Record individual work and review contributions honestly. Team leads coordinate; they must not attribute a whole implementation to members without evidence. Disclose reused libraries/code, licences and AI assistance; contributors remain responsible for checking output. Never commit credentials or private data.
