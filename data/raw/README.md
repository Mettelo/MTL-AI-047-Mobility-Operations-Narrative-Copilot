# Immutable raw inputs
Store the original UCI archive and untouched extracted hour.csv/day.csv here locally. Keep Readme.txt and its hash; copy reference documentation to data/reference/ as needed.

Do not repair, impute, overwrite or combine raw files. Derived files belong in data/processed/. The team downloader must restrict extraction paths and expected filenames. Raw downloads are excluded from version control; document exact download and SHA-256 checks so reviewers can rebuild them. Small redistributed examples require attribution and a clear derived/synthetic label.
